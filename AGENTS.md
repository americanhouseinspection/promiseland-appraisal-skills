# Agent instructions

This repository packages public skills and a read-only MCP connection for Promise Land Appraisal.

- Keep descriptions grounded in the linked public website and published guides.
- Keep API and MCP use anonymous and read-only. Do not add appraisal submission, address-level coverage decisions, property valuations, fee estimates, booking, payment, or request storage.
- Do not send a person's address, phone number, or email through a search or MCP call. The person reviews and sends any contact draft.
- Do not invent credentials, service coverage, office locations, fees, ratings, reviews, or business profiles.
- Keep the skills aligned with the canonical site guides linked in the README.
